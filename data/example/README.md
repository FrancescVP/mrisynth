# Data Example

This directory shows the expected input format for the pipeline.  
`raw/` contains **synthetic** NIfTI files (16×16×16 voxels, random data) that reproduce the exact nnUNet layout the preprocessing script expects.

Downstream formats (preprocessed `.npz` and latent `.pt`) are generated by the repo's own scripts — their layouts are documented below.

---

## Pipeline overview

```
raw/          ──▶  gan-preprocess  ──▶  preprocessed/  ──▶  generate_latents.py  ──▶  latents/
(this folder)       (repo script)        (generated)          (repo script)           (generated)
```

---

## Stage 1 — Raw input (nnUNet format)

```
raw/
├── dataset.json               ← channel names, labels, dataset metadata
├── imagesTr/
│   ├── EXAMPLE_Pat001_0000.nii.gz   # T1CE  — synthesis target
│   ├── EXAMPLE_Pat001_0001.nii.gz   # T1n   — primary conditioning input
│   ├── EXAMPLE_Pat001_0002.nii.gz   # T2FLAIR — secondary conditioning input
│   ├── EXAMPLE_Pat001_0003.nii.gz   # T2w   — secondary conditioning input
│   ├── EXAMPLE_Pat002_0000.nii.gz
│   ├── EXAMPLE_Pat002_0001.nii.gz
│   ├── EXAMPLE_Pat002_0002.nii.gz
│   ├── EXAMPLE_Pat002_0003.nii.gz
│   ├── EXAMPLE_Pat003_0000.nii.gz
│   ├── EXAMPLE_Pat003_0001.nii.gz
│   ├── EXAMPLE_Pat003_0002.nii.gz
│   └── EXAMPLE_Pat003_0003.nii.gz
└── labelsTr/
    ├── EXAMPLE_Pat001.nii.gz        # Segmentation (int8)
    ├── EXAMPLE_Pat002.nii.gz
    └── EXAMPLE_Pat003.nii.gz
```

Each `.nii.gz` in `imagesTr/` is a single-channel float32 NIfTI volume at 1 mm isotropic spacing.  
The four-digit suffix (`_0000`–`_0003`) identifies the modality channel (defined in `dataset.json`).  
Segmentation labels: `0=background`, `1=NETC`, `2=SNFH`, `3=ET`.

Case IDs follow the BraTS 2023 naming convention:  
`{SUBTYPE}_{StudyID}` — subtypes include `GLI`, `MEN`, `MET`, `GBM`, `PED`.

**Generate preprocessed data from this input:**

```bash
uv run gan-preprocess \
    --dataset data/example/raw \
    --output  /path/to/preprocessed \
    --normalization zscore_nonzero \
    --num-workers 1
```

## Stage 2 — Preprocessed (`.npz` + `.json`)

Output of `gan-preprocess`. One pair of files per case, flat directory. Not included here — generated by the script above.

```
preprocessed/
├── EXAMPLE_Pat001.npz
└── EXAMPLE_Pat001.json
```

### `.npz` layout

```python
import numpy as np
d = np.load("EXAMPLE_Pat001.npz")

d["data"]   # float32, shape (4, D, H, W) — Z-score normalised, cropped to nonzero
            #   channel 0: T1CE     (synthesis target)
            #   channel 1: T1n      (primary input)
            #   channel 2: T2FLAIR  (secondary input)
            #   channel 3: T2w      (secondary input)

d["seg"]    # int8, shape (D, H, W)
            #   0 = background
            #   1 = NETC  (non-enhancing tumour core)
            #   2 = SNFH  (surrounding non-enhancing FLAIR hyperintensity)
            #   3 = ET    (enhancing tumour)
```

Spatial dimensions `(D, H, W)` vary per case after crop-to-nonzero. Typical size: ~130×170×130 at 1 mm isotropic.

### `.json` sidecar

```json
{
  "case_id": "EXAMPLE_Pat001",
  "spacing": [1.0, 1.0, 1.0],
  "affine": [[-1,0,0,X],[0,1,0,Y],[0,0,1,Z],[0,0,0,1]],
  "original_shape": [182, 218, 182],
  "channel_names": {"0":"T1CE","1":"T1","2":"T2FLAIR","3":"T2"},
  "labels": {"background":0,"NETC":1,"SNFH":2,"ET":3},
  "crop_bbox": [[z0,z1],[y0,y1],[x0,x1]],
  "shape_after_crop": [D, H, W],
  "spacing_after_resample": [1.0, 1.0, 1.0],
  "foreground_voxels": 1530143,
  "preprocess_config": {
    "normalization": "zscore_nonzero",
    "crop_to_nonzero": true,
    "image_resample_order": 3,
    "seg_resample_order": 1
  }
}
```

## Stage 3 — Latent cache (`.pt`)

Output of `scripts/generate_latents.py`. Not included here — generated from preprocessed data.

```
latents/
├── train/
│   └── EXAMPLE_Pat001/
│       ├── EXAMPLE_Pat001-t1c_z_mu.pt      # float16, shape (4, D/4, H/4, W/4)
│       ├── EXAMPLE_Pat001-t1c_z_sigma.pt   # float32, shape (4, D/4, H/4, W/4)
│       ├── EXAMPLE_Pat001-t1n_z_mu.pt
│       ├── EXAMPLE_Pat001-t1n_z_sigma.pt
│       ├── EXAMPLE_Pat001-t2f_z_mu.pt
│       └── EXAMPLE_Pat001-t2f_z_sigma.pt
└── val/
    └── ...
```

The MAISI VAE compresses spatial dimensions by 4× in each axis. The 4 latent channels are fixed (VAE bottleneck width). Modality suffixes: `t1c` = T1CE, `t1n` = T1n, `t2f` = T2FLAIR, `t2w` = T2w.

**Generate latents from preprocessed data:**

```bash
uv run python scripts/generate_latents.py \
    --data_dir /path/to/preprocessed \
    --vae_ckpt pretrained/autoencoder_epoch273.pt \
    --out_dir  latents/dataset \
    --device   cuda:0
```
